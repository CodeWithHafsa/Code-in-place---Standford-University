#### Question # 01

A self-driving car’s camera counts the pedestrians it sees in one second of video. Call that count 
X.

Which of these is a random variable?

* X, the number of pedestrians it sees
* X = 3, it sees exactly three pedestrians
* P(X = 3), the chance it sees exactly three pedestrians

**Answer:** Option1: X, the number of pedestrians it sees

#### Question # 02

A basketball player takes 10 free throws. Each one goes in with the same chance, independently of the others. Let 
X be the number of free throws that go in.

What kind of random variable is 
X?

* Bernoulli
* Binomial
* Neither

**Answer:** Option2: Binomial
