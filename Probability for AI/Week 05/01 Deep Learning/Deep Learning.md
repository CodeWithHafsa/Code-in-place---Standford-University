### Example 01

At the start of this lesson, a network read handwritten digits, and it might have looked like magic.

Now you know what is inside. If a friend asked you how it works, what would you tell them?

**Answer:**

Based on the handwritten-digit example, I would explain it to a friend like this:

A neural network is a computer system that learns by looking at lots of examples. When it sees a handwritten digit, it breaks the image down into pixels and passes the information through different layers of artificial neurons. Each layer helps the network recognize patterns and features. It learns by adjusting the connections between neurons whenever it makes mistakes. After training on many examples, it can recognize new handwritten digits and predict which number they represent.
