## Change of Heart

When the user types a word that is already in the dictionary, print the emoji it has now, then ask for its new emoji like before.

Here is a sample run:

```
Let's build your emoji dictionary! Press enter when you are done.
Word: pizza
Emoji for pizza: 🍕
Word: pizza
pizza already has an emoji: 🍕
Emoji for pizza: 🍝
Word: cat
Emoji for cat: 🐱
Word:
Words in your dictionary: 2
pizza: 🍝
cat: 🐱
Enter a sentence: I love pizza
I love 🍝
Enter a sentence:
```

### Given Code

```python
# Asks the user for words and their emoji until they press enter, and returns the dictionary.
def build_emoji_dict():
    emoji_dict = {}
    word = input("Word: ")
    word = word.lower()
    while word != "":
        emoji = input(f"Emoji for {word}: ")
        emoji_dict[word] = emoji
        word = input("Word: ")
        word = word.lower()
    return emoji_dict


# Prints every word in the dictionary next to its emoji.
def print_emoji_dict(emoji_dict):
    for word in emoji_dict:
        emoji = emoji_dict[word]
        print(f"{word}: {emoji}")


# Swaps every word that has an emoji for its emoji. Other words stay the same.
def translate(sentence, emoji_dict):
    result = ""
    words = sentence.split()
    for word in words:
        lower_word = word.lower()
        if lower_word in emoji_dict:
            emoji = emoji_dict[lower_word]
            result += emoji + " "
        else:
            result += word + " "
    return result


def main():
    print("Let's build your emoji dictionary! Press enter when you are done.")
    emoji_dict = build_emoji_dict()
    num_words = len(emoji_dict)
    print(f"Words in your dictionary: {num_words}")
    print_emoji_dict(emoji_dict)
    sentence = input("Enter a sentence: ")
    while sentence != "":
        translation = translate(sentence, emoji_dict)
        print(translation)
        sentence = input("Enter a sentence: ")


if __name__ == "__main__":
    main()
```

#### How it works:

1. `if word in emoji_dict` checks whether the word already exists.
2. `emoji_dict[word]` gets its current emoji.
3. The program prints the current emoji.
4. It asks for a new emoji.
5. `emoji_dict[word] = emoji` replaces the old emoji with the new one.
