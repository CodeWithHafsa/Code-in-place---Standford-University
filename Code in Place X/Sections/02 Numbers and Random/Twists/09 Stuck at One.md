## Stuck at One

*A twist on Khansole Academy from your section. Try it yourself, then compare your code with the solution.*

You can answer correctly forever, but Khansole Academy never lets you finish! Find the bug and fix it.

Here is what happens now:

```
Khansole Academy
What is 55 + 11?
Your answer: 66
Correct!
You've gotten 1 correct in a row.

What is 84 + 25?
Your answer: 109
Correct!
You've gotten 1 correct in a row.
```

### Given Code

```python
from random import randint

def main():
    print("Khansole Academy")

    correct_in_a_row = 0

    while correct_in_a_row < 3:
        correct_in_a_row = 0

        # Generate two random numbers
        num1 = randint(10, 99)
        num2 = randint(10, 99)

        # Prompt the user with the problem
        print(f"What is {num1} + {num2}?")
        user_ans = int(input("Your answer: "))
        true_ans = num1 + num2

        if user_ans == true_ans:
            print("Correct!")
            correct_in_a_row += 1
            print(f"You've gotten {correct_in_a_row} correct in a row.")
        else:
            print("Incorrect.")
            correct_in_a_row = 0
            print(f"The expected answer is {true_ans}")
        print()

    print("Congratulations! You mastered addition.")

if __name__ == '__main__':
    main()
```

---
#### What changed?
The bug is that `correct_in_a_row = 0` is inside the `while` loop, so the counter resets to zero every time a new question starts.

Fix: Remove that line from inside the loop. The counter should only reset when the player answers incorrectly.

---
