## Completing CS 106A

Code in Place is loosely based on Stanford's introductory programming course, CS 106A. [Here's](https://web.stanford.edu/class/cs106a/) the current offering, taught by Chris and Mehran. The syllabus from that class differed slightly from what we learned in Code in Place, so if you want to follow through with the rest of CS 106A, you'll need to do the following:

* [Install PyCharm.](https://web.stanford.edu/class/cs106a/#/installing-pycharm) CS 106A has students program on IDEs installed in their own computers, and some of the libraries that the class uses aren't fully supported by the online CiP Platform.

* Follow the Second Half of CS 106A Roadmap found in your student homepage!

## CS 106B

The sequel class to [CS 106A](https://web.stanford.edu/class/cs106b/) at Stanford is CS 106B. In this class, you further develop your toolkit by deepening your understanding of how a computer represents data and learning about additional problem-solving techniques and structures. The class is taught in C++, one of the most popular programming languages in history. 

* Course website: http://web.stanford.edu/class/cs106b/

* Old recorded lectures: https://see.stanford.edu/Course

* [Python for Everybody](https://www.py4e.com/)
contains free resources for learning Python. Thank you Vamsi S for the recommendation!

* [Think Python](https://greenteapress.com/wp/think-python-2e/) is a fantastic, free,  reference textbook for the Python programmer, new or old. It includes explanations, examples, problems and, via github, solutions. Thanks to Steve G for the recommendation!

* Raymond Hettinger has some fantastic talks on the design and philosophy of Python programs. We'd recommend [The Mental Game of Python](https://www.youtube.com/watch?v=Uwuv05aZ6ug), [Transforming Code into Beautiful](https://www.youtube.com/watch?v=OSGv2VnC0go), [Idiomatic Python](https://www.youtube.com/watch?v=OSGv2VnC0go) and [Best practices for beautiful intelligible code.](https://www.youtube.com/watch?v=wf-BqAjZb8M)  *Thanks to Mark F for the recommendation!*

* [Pycoders](https://www.youtube.com/watch?v=wf-BqAjZb8M) has a weekly newsletter outlining interesting topics related to Python. Thanks to Trunojoyo (Atun) A for the recommendation!

* [PyCon](https://us.pycon.org/2021/) is one of the largest Python conferences in the world, and tickets are relatively affordable.  Thanks to Nayeon S for the recommendation!

* [Corey Shaefer](https://www.youtube.com/channel/UCCezIgC97PvUuR4_gbFUs5g) has a YouTube channel which is a fantastic resource for people both struggling with the programming basics and learning new skills. He mainly uses Python. He has short videos on very specific concepts, like loops. Thanks to Gretel U for the recommendation!

* Microsoft has an [Introduction to Python](https://www.youtube.com/watch?v=jFCNu1-Xdsw&list=PLlrxD0HtieHhS8VzuMCfQD4uJ9yne1mE6)  series which is broken down into small lessons on specific topics, so you can look up specifics that you are struggling with or just browse around to find new things to learn.  *Thanks to Gretel U for the recommendation!*

* [TutorialsPoint Python.](https://www.tutorialspoint.com/python/index.htm) *Thank you to Tejas S. for the recommendation*
